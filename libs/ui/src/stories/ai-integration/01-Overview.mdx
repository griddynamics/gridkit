## What It Is

GridKit ships a complete AI integration system that lets LLMs produce real GridKit UI without writing React code.

Two modes, one library:

| Mode          | LLM output       | Entry point                                | Best for                            |
| ------------- | ---------------- | ------------------------------------------ | ----------------------------------- |
| **A2UI mode** | A2UI JSON spec   | `buildA2UISystemPrompt` + `renderA2UISpec` | Conversational agents, dynamic UI   |
| **Code mode** | React/TSX source | `buildClaudeSystemPrompt`                  | Developer tools, design scaffolding |

## Simple end-to-end picture

**A2UI mode:**

```text
user message
  -> LLM reads system prompt from buildA2UISystemPrompt
  -> LLM returns A2UI JSON spec
  -> renderA2UISpec turns it into live GridKit components
```

**Code mode:**

```text
user message
  -> LLM reads system prompt from buildClaudeSystemPrompt
  -> LLM returns React/TSX code
  -> code runs in the React tree
```

## How to import

```typescript
// A2UI mode — LLM side
import { buildA2UISystemPrompt, buildA2UIGeminiRequest, A2UI_SPEC_SCHEMA } from 'gd-design-library/ai';
// A2UI mode — React renderer
import { renderA2UISpec, A2UI_RENDERER_COMPONENT_TYPES } from 'gd-design-library';

// Code mode
import { buildClaudeSystemPrompt, buildGPT4Prompt, buildGeminiPrompt } from 'gd-design-library/ai';
```

## When to use each mode

**Use A2UI mode when:**

- the UI is generated at runtime in response to user messages
- you cannot or do not want to execute generated code
- you need instant rendering without a build step
- you want the LLM to stay within approved GridKit components

**Use Code mode when:**

- you are building a developer tool, scaffolder, or Storybook helper
- you need full React flexibility and are running the code yourself

## What makes this work

The system prompt is derived directly from the live GridKit component map.

When you call `buildA2UISystemPrompt()` it generates a prompt that lists every available component, its props, and the rules for using it.

You never maintain a hand-written catalogue — the prompt stays in sync automatically.
