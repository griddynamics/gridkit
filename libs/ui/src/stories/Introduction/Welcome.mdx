# 👋 Welcome to GridKit v{version}

**GridKit** is a modern, scalable design system and component library created by Grid Dynamics. It
helps teams build consistent, accessible, and high-performing web interfaces across products and domains.

### ✨ Key Features

- Reusable, accessible React components
- Design tokens mapped directly from Figma
- Responsive and theme-aware layout system
- Optimized for e-commerce, MVPs, and chat UIs

### 🚀 Benefits

- Accelerate development & reduce rework
- Ensure visual and behavioral consistency
- Empower teams with ready-to-use patterns
- Scale effortlessly across multiple products

## 📚 What You'll Find Here

GridKit follows **Atomic Design** methodology for component organization:

- **Atoms** — basic building blocks (Button, Input, Icon, Typography, etc.)
- **Molecules** — simple combinations (Form, Tabs, Accordion, Rating, etc.)
- **Organisms** — complex UI sections (Header, Modal, Card, Carousel, etc.)
- **Layout** — structural components (Row, Column, FlexContainer, etc.)
- **Design Tokens** — spacing, typography, color, and theming
- **Patterns & Best Practices** — responsive layouts, validation, accessibility, and more
- **AX Strategies** — how to build ethical, human-centered AI interfaces
