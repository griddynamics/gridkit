# Loader, Separator, and Skeleton migration manifest

`react-component-ast` and `web-component-generator` were unavailable for this run. This reviewed manual manifest follows the self-migration-agent fallback and was derived from each React component's source, public types, tokens, tests, exports, local stories, and published Storybook inventory.

| React component | Classification | Custom element | Attributes / properties                                                                                              | Slots                                      | Parts                        | Events / methods | Accessibility and compatibility                                                                                                                                                                            |
| --------------- | -------------- | -------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | ---------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Loader          | element        | `gd-loader`    | `name`, `variant`, `size`, `rounded`, `animationProps`, `withWrapper`, `styles`, `theme`                             | default custom content                     | `wrapper`, `loader`, `dot`   | none             | Inner loader exposes `role=status` and an accessible loading name. Full-page uses the native popover top layer. React `as` becomes the stable custom-element host plus `withWrapper`.                      |
| Separator       | element        | `gd-separator` | `orientation`, `length`, `color`, `size`, `variant`, `as`, `label`, `labelPosition`, `labelColor`, `styles`, `theme` | none; the React API accepts a string label | `separator`, `line`, `label` | none             | `as` selects the internal `div`, `hr`, or `span`. An `hr` with a label uses a `div` wrapper and `hr` line segments, matching React. React box-spacing props remain available through `styles` or host CSS. |
| Skeleton        | element        | `gd-skeleton`  | `variant`, `width`, `height`, `backgroundColor`, `animationName`, `animationProps`, `styles`, `theme`                | default child content                      | `skeleton`                   | none             | The native host accepts ARIA attributes. `animationName = null` disables the built-in animation. React `className` maps to the custom-element `class` attribute; children map to the default slot.         |

All three elements resolve their source token trees. They define no component-owned `static styles`; runtime stylesheets are generated from token blocks and documented public style properties.
