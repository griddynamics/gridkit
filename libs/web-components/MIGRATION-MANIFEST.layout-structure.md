# Layout & Structure migration manifest

The `react-component-ast` extractor and `web-component-generator` were run for `Portal` and `Scroll`; their temporary IR and generated manifests were reviewed and removed as required. Those generators were unavailable for the later ChatContainer run, so its reviewed manual manifest was derived from the complete source implementation, public types, tokens, tests, exports, four published stories, and three source play functions. The hosted source baselines were validated against source metadata at `react-layout-structure-portal--default`, `react-layout-structure-scroll--interactive-example`, and all five indexed ChatContainer entries (Docs plus four stories), including the matching page title, sidebar entry, preview iframe/story ID, post-play state, content, semantics, controls, and geometry.

## Classification

| Source        | Classification | Decision                                                                                                                                                                                                                                                                                                                                                           |
| ------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Column        | `element`      | The dedicated target preserves browser-relevant flex-element props, the complete Box style set, `styles`, classes, children, refs, tokens, dedicated stories, and the `as` semantic selector. As with Typography, `as` changes the token-backed inner semantic node while the registered `gd-column` host remains stable.                                          |
| ChatContainer | `element`      | Owns responsive sidebar state, five content regions, minified navigation, token-backed breakpoint behavior, user toggle notification, and imperative open/close/toggle methods. React content props become slots and the forwarded ref becomes the element API.                                                                                                    |
| Row           | `element`      | Same platform contract as Column. `gd-row` preserves `as`, flex aliases, Box props, style precedence, and slotted children using the same semantic inner-node approach as Typography.                                                                                                                                                                              |
| FlexContainer | `element`      | `gd-flex-container` preserves the full Box style surface, native host classes, styles, children, defaults, and both React behavior stories. It does not redeclare React `className`; consumers use the platform `class` attribute/property. The token-backed host uses `display: contents` so the inner root occupies the same layout position as the React `div`. |
| Portal        | `element`      | `gd-portal` preserves the representable native contract as a dedicated component: target selection, original-node placement, optional token-backed wrapper, wrapper variant/tag, custom styles, body scroll blocking, cleanup, and all four source stories. React-only context and synthetic events map to native DOM ownership/events.                            |
| Scroll        | `element`      | Owns overflow measurement, visibility state, auto-hide timing, pointer dragging, token-backed scrollbar rendering, and an imperative scrolling surface.                                                                                                                                                                                                            |

## Reviewed ChatContainer platform API

| React contract                                        | Platform mapping                                                                                                                                                                                       |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `isOpen`                                              | Reflected `is-open` boolean property/attribute containing the current state. It remains `isOpen`, rather than adding a redundant `open` property that would collide with the required `open()` method. |
| `showSidebarAsideControl`, `showSidebarHeaderControl` | Boolean properties/attributes retaining the two independent control-visibility decisions.                                                                                                              |
| `children`                                            | Default slot in the semantic `<main>`.                                                                                                                                                                 |
| `headerContent`                                       | `slot="header"` in the main `<header>`.                                                                                                                                                                |
| `sidebarContent`                                      | `slot="sidebar"` in the expanded `<aside>`.                                                                                                                                                            |
| `sidebarHeaderContent`                                | `slot="sidebar-header"` in the sidebar `<header>`.                                                                                                                                                     |
| `sidebarMinifiedContent`                              | `slot="sidebar-minified"` in the compact `<aside>`.                                                                                                                                                    |
| `onToggleSidebar`                                     | Typed, bubbling, composed `gd-toggle-sidebar` event with `{ open: boolean }` detail for user-equivalent toggles.                                                                                       |
| forwarded `ref`                                       | The element itself; `isOpen`, `open()`, `close()`, and `toggle()` form the imperative API.                                                                                                             |
| `styles`, Box props, `theme`                          | JavaScript properties resolved in source order from the existing `chat` token tree.                                                                                                                    |
| `className`                                           | Omitted as a component property/control; consumers use native `class` / `HTMLElement.className`.                                                                                                       |

The internal toggle controls compose the migrated `gd-button` and `gd-icon` elements and use the source `chat.toggleButton` and `chat.toggleIcon` tokens. No ReactNode, React ref, callback property, catalog SVG duplication, or parallel component CSS is exposed by the Custom Element.

## Reviewed Scroll platform API

| React contract           | Platform mapping                                                                                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vertical`, `horizontal` | Reflected string attributes: `auto`, `hidden`, or `visible`.                                                                                                                                                                          |
| `autoHide`               | Reflected `auto-hide` boolean attribute/property.                                                                                                                                                                                     |
| `styles`, `theme`        | JavaScript-only object properties.                                                                                                                                                                                                    |
| `children`               | Default slot; content remains consumer-owned.                                                                                                                                                                                         |
| forwarded container ref  | The `gd-scroll` host is the native scrolling element and exposes inherited `scrollTop`, `scrollLeft`, `scrollTo`, and related APIs. `refresh()` re-measures imperative content changes.                                               |
| styled internals         | Stable `content`, `scrollbars`, `scrollbar`, `vertical-scrollbar`, `horizontal-scrollbar`, `thumb`, `vertical-thumb`, and `horizontal-thumb` CSS parts.                                                                               |
| local state/effects      | Private reactive visibility/scrolling state, `ResizeObserver` plus the source's 300 ms overflow polling behavior, scroll listener, one auto-hide timer, and document pointer listeners owned and cleaned up by the element lifecycle. |
| callbacks                | None in the source; no custom event or framework event adapter is required.                                                                                                                                                           |

All component visual rules are resolved from the existing `scroll` component token tree through `resolveThemeTree`. Measured thumb position/size and flat consumer-provided `styles` declarations are mirrored inline at runtime. The latter is required because document rules targeting a custom-element host outrank Shadow DOM `:host` rules; it preserves the source's CSS-in-JS precedence over GridKit's global reset while leaving an explicit native `style` declaration authoritative. Numeric CSS-in-JS lengths use React/Emotion pixel semantics. `content.horizontalHidden` was added to the owning token tree for the source's horizontal-hidden constraint.

## Reviewed Portal platform API

| React contract        | Platform mapping                                                                                                                 |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `container`           | JavaScript `Element \| DocumentFragment \| null` property; null defaults to `document.body`.                                     |
| `wrapperVariant`      | `inline`, `section`, or `fullPage` property / `wrapper-variant` attribute using the shared Wrapper token tree.                   |
| `withWrapper`         | Boolean property / `with-wrapper` attribute. The JavaScript property supports the source default of `true` and explicit `false`. |
| `blocksScroll`        | Reflected `blocks-scroll` boolean property with lifecycle cleanup.                                                               |
| `WrapperView`         | Exact source-named property with a `wrapper-view` declarative attribute for semantic wrapper tags.                               |
| `styles`, `theme`     | JavaScript-only object properties applied after the selected wrapper tokens.                                                     |
| `children`            | Original light-DOM nodes are moved rather than cloned, preserving identity and native listeners.                                 |
| forwarded wrapper ref | `portalRoot` exposes the generated wrapper; it is null when `withWrapper` is false.                                              |

React context and synthetic event bubbling are framework-runtime behavior rather than component props. The native port retains the equivalent platform semantics—DOM node identity, native event propagation, and explicit framework adapters where React-specific behavior is required—without using that runtime difference to erase the exported component.

Portal ownership is also preserved after a plain `DocumentFragment` target is consumed into another node: live comment markers receive late children and teardown reclaims every owned node. Body scroll locks are reference-counted per document and restore the exact prior inline overflow value after the final portal releases its lock.

Angular and Vue use direct Custom Element property bindings and are compiled by the existing consumer fixtures. Because Scroll emits no component event, there is no React custom-event map to generate; React consumers can use the native element and an element ref for object properties and imperative scrolling.

## Layout component contract

The source taxonomy is preserved with dedicated `gd-column`, `gd-row`, `gd-flex-container`, and `gd-portal` implementation directories and separate Storybook entries matching every React Layout & Structure export.

`gd-column` and `gd-row` expose `as`, `align`, `justify`, `gutter`, `isWrap`, `isReversed`, `flex`, `styles`, and the browser-relevant `BoxCssComponentProps` surface as JavaScript properties with kebab-case attribute mappings for primitive values. As with Typography, `as` selects the semantic element carrying `part="root"` inside the shadow tree while the registered public host remains `gd-column` or `gd-row`; React component constructors are intentionally unsupported. `gd-flex-container` exposes the complete Box style surface and `styles`; all layout elements inherit native host `class`, `id`, `tabIndex`, and `style` behavior rather than redeclaring React aliases. All three render slotted children, expose `part="root"`, resolve their source token tree, preserve source style precedence, and are covered in SSR, Angular, Vue, unit, Storybook, and parity checks.

### React-to-platform prop relevance decisions

| Source prop                                     | Target decision                     | Reason                                                                                                                                                                                                                                           |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Column/Row `as`                                 | Retained as semantic inner element  | Explicit compatibility decision matching Typography: the public custom-element host remains stable while `part="root"` changes to the selected semantic HTML element. React component constructors remain unsupported.                           |
| Layout `className`                              | Native `class`                      | Every custom element already inherits `HTMLElement.className` and the declarative `class` attribute. A second reactive property or shadow-root forwarding contract is redundant and external class selectors cannot style a copied shadow class. |
| Portal `WrapperView`                            | Retained                            | It selects the independently rendered portal wrapper outside the custom-element host and therefore changes observable DOM semantics.                                                                                                             |
| Typography/Wrapper/Separator semantic selectors | Retained in their owning components | They select semantic painted/accessibility nodes whose behavior is independently tested; they are not generic host-polymorphism aliases.                                                                                                         |
